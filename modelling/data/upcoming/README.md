# Upcoming Race Inputs

Upcoming-race files must be added only after M2 has verified them.

Recommended files:

- `<race>_post_quali.csv`
- `<race>_post_grid.csv`

Post-quali files must not contain grid position or race results.
Post-grid files require a verified final grid and a verified pre-race cutoff.

The existing collector writes equivalent stage tables for Bahrain and the four-race
pilot. Add timestamps and verification evidence before publishing an upcoming
race forecast.
