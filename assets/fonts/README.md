# APEX typography

Local Google Fonts assets keep the dashboard's typography available offline.

- Barlow Condensed Bold: `https://github.com/google/fonts/tree/main/ofl/barlowcondensed`
- Space Grotesk variable: `https://github.com/google/fonts/tree/main/ofl/spacegrotesk`
- JetBrains Mono variable: `https://github.com/google/fonts/tree/main/ofl/jetbrainsmono`

Each font's original SIL Open Font License is included alongside its file. The font files are unmodified; local filenames differ only for simpler asset loading. The app embeds these local files in its CSS and requires no font CDN requests. System fonts provide a fallback if an asset is unavailable.
